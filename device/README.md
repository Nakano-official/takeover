# 欠員アラート端末（M5Stack）セットアップ

## 現在進めている方式：大学ログイン済みPCからUSBで通知

GASの公開範囲を「Ryukoku Universityの全員」に維持するため、
現在は [PC中継の手順](../tools/usb-relay/README.md) を使います。
書き込むコードは `usb_vacancy_alert/usb_vacancy_alert.ino` です。
以下は以前のWi-Fi直接接続方式の記録です。

職員向けの物理アラート端末。新しい欠員が出ると **メロディー1回＋画面点灯（赤）** で知らせ、
本体ボタンで消灯する。仕様は `docs/spec/decisions.md` D6（案1）。

```
[学生が欠勤連絡] → GAS(vacancies に1件追加・Google Chat通知) → [M5Stackが3秒ごとに確認]
                                                          → 新着なら「メロディー＋赤点灯」
                                                          → 職員がボタンで確認(消灯)
```

端末は GAS の **読み取り専用エンドポイント**を叩くだけ。返るのは
「未対応件数＋最新の欠員連番」のみで、**氏名などの個人情報は一切返さない**（D3と整合）。

---

## 1. GAS側の準備

### (a) スクリプトプロパティに端末用トークンを設定
GASエディタ → プロジェクトの設定 → スクリプトプロパティ に追加：

| キー | 値 |
|---|---|
| `DEVICE_TOKEN` | 推測されにくい長い文字列（例：32文字のランダム英数字） |

> このトークンを知っている端末だけが件数を取得できる。スケッチ側と**完全一致**させること。

### (b) Web App を「全員アクセス可」で（再）デプロイ
端末は Google ログインを持たないため、デプロイ設定を次にする：

- **次のユーザーとして実行**：自分（デプロイする職員）
- **アクセスできるユーザー**：**全員**

> 画面側は `getCurrentUser_` で必ずロール判定するため、匿名でアクセスされても
> 個人情報は表示されない。端末エンドポイントは `DEVICE_TOKEN` で保護される。

デプロイ後に表示される **`/exec` で終わる URL** を控える（スケッチに貼る）。

### (c) 動作確認（ネットワーク不要）
GASエディタで関数 `testDevicePoll` を実行 → 実行ログに件数・最新連番が出ればOK。
ブラウザで `（/exec URL）?device=alert&token=（DEVICE_TOKEN）` を開くと、
`{"ok":true,"count":...,"latest":...}` が返る。

## 2. 端末側（Arduino IDE）の準備

1. **ボード追加**：環境設定の「追加のボードマネージャURL」に M5Stack のURLを入れ、
   ボードマネージャで「M5Stack」(ESP32) をインストール。ボードは **M5Stack-Core-ESP32** を選択。
2. **ライブラリ**：ライブラリマネージャで **M5Unified** と **WiFiManager（tzapu）** をインストール。
3. **スケッチを開く**：`device/alert_m5stack/alert_m5stack.ino`
4. 端末をUSB接続して**書き込み**。SSID・パスワード等をコードへ書く必要はない。

### 初回起動時の設定

1. M5Stack Basicを起動する。
2. スマートフォンのWi-Fi設定で **`Shift-M5Stack-Setup`** に接続する。
3. 設定用パスワード **`shiftsetup`** を入力する。
4. 設定画面が自動表示されない場合は、ブラウザで **`192.168.4.1`** を開く。
5. 次の値を入力して保存する。
   - 接続先Wi-FiのSSIDと共通パスワード（ESP32は2.4GHzのみ）
   - `GAS Web App URL`：手順1(b)の `/exec` URL
   - `DEVICE_TOKEN`：手順1(a)と同じトークン

設定値はM5Stack内部の不揮発領域へ保存され、次回から自動接続する。設定を変更する場合は、
**ボタンAを押した状態で電源を入れる**と設定画面を再度開ける。

## 3. 使い方・挙動

| 状態 | 画面 | 音 |
|---|---|---|
| 待機（新着なし） | 緑背景・`ack / waiting` | 無音 |
| 新着あり（未確認） | **赤背景**・`NEW! press btn`・未対応件数 | **ドレミファソラシド・ドシラソファミレドを1回** |
| ボタンA押下 | 緑背景に戻る（消灯＝確認済み） | 無音 |

- 鳴り続けない。確認したら消える。さらに別の新着が来たら、また1回鳴って点灯。
- 起動直後の既存欠員では鳴らない（最新連番を基準として覚えるだけ）。
- M5StackはWi-Fiへ常時接続して待機し、3秒ごとにGASを確認する。

---

## 4. トラブルシュート

| 症状 | 確認 |
|---|---|
| 初回設定画面が出ない | `Shift-M5Stack-Setup` に接続後、ブラウザで `192.168.4.1` を開く |
| 画面が `WiFi...` のまま | SSID/パスワード、Wi-Fiの2.4GHz対応（ESP32は5GHz不可） |
| `unauthorized` がシリアルに出る | `DEVICE_TOKEN` がGASと端末で一致しているか |
| `HTTP error: 401/403` | Web Appのアクセス権が「全員」になっているか・再デプロイしたか |
| 件数が常に0 | `vacancies` に未対応（result空）の行があるか／`testDevicePoll` で集計を確認 |
| 日本語が出したい | M5Unifiedの日本語フォント設定が別途必要（既定は英数字表示） |

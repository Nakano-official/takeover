# スマホ接続だけを確認するコード

使うファイルは、このフォルダの `phone_connect_simple.ino` です。
M5Stack Basic用。Arduino IDEのボードは `M5Stack-Core-ESP32`、追加ライブラリは `M5Unified` を使います。
WiFiとWebServerはESP32ボードパッケージに付属します。WiFiManagerは不要です。

1. USBで接続し、このコードを書き込みます。
2. 本体に `PHONE TEST v1` が表示されます。
3. スマホのWi-Fiで `M5-Simple` を選び、パスワード `12345678` で接続します。
4. インターネット接続なしと表示されても、そのまま接続を維持します。
5. ブラウザで `http://192.168.4.1` を開きます（自動表示はしません）。
6. 「本体の画面を緑にする」を押し、本体が緑色で `PHONE OK!` と表示されれば成功です。

起動するたびに設定用Wi-Fiが開きます。ボタン操作も時間制限もありません。
GASへの接続、欠員通知、接続先Wi-Fi設定の保存は行いません。
本体に保存済みの以前の接続設定は消しませんが、このコードでは使用しません。
本体への書き込み・動作確認は別途必要です。

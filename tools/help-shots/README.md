# help-shots — ヘルプ用の画面を架空データで組み立てる（D51）

画面右上の「？ ヘルプ」（`src/help-*.html`）に載せる画像を撮るための道具。
ほかの `tools/` と同じく **`clasp push` の対象外**。

## なぜ実際の画面を撮らないのか

- このリポジトリは **Public**。実際の画面には利用学生・スタッフの氏名、教室と時刻が写る。
  名前を塗っても「支援を受けている学生がこの教室にこの時間にいる」は読めてしまう。
- 撮影のために本番DBへ架空データを入れることもしない。`/dev` も本番DBを見ているので危険。

そこで、検証ハーネス（`tools/gas-harness.js`）のメモリ上のシートに架空データを入れ、
**本物の `src/*.gs` をそのまま動かして**画面を組み立てる。ロジックは本番と同じなので、
「欠員対応中」「代行に入れます」「決着待ち」なども本物の判定で出る。

## 使い方

```
node tools/help-shots/render.js
```

`tools/help-shots/out/` に、ブラウザで直接開ける HTML ができる（`.gitignore` 済み）。

| ファイル | 見る人 | 画面 |
|---|---|---|
| `student-home.html` | 学生（山田 太郎） | シフト確認 |
| `student-absence.html` | 学生 | 欠勤連絡（木曜4限を選んだ状態） |
| `student-vacancies.html` | 学生 | 欠員一覧 |
| `student-respond.html` | 学生 | 代行依頼への回答 |
| `staff-home.html` | 職員（支援室 職員） | シフト確認 |
| `staff-manage.html` | 職員 | 欠員補充管理 |
| `staff-input.html` | 職員 | シフト入力 |
| `staff-vacancies.html` | 職員 | 欠員一覧 |

右上の「？ ヘルプ」も押せる（ヘルプの中身も本物の `getHelp` で作って埋め込んである）。

## 中身

| ファイル | 役割 |
|---|---|
| `demo-data.js` | 架空データ（スクショ用の仮のスプレッドシート）。**日時は 2026-11-10 火曜 9:00 に固定** |
| `render.js` | 架空データで画面を組み立てて書き出す |

日時を固定しているので、いつ撮っても同じ画面になる（夜に回して日付をまたぐ問題も起きない）。

## 写したい状態が無いとき

`demo-data.js` の冒頭に「この週の出来事」がある。写したい状態（例：別の種類の欠員）が無ければ、
そこにコマ・欠員を足す。**氏名・教室・電話はすべて架空**で書くこと。

## できないこと

- ボタンを押したときの書き込み（欠勤の登録・代行に入る など）は「成功した」と返すだけで、
  画面は変わらない。押した後の画面を撮りたいときは、その状態を `demo-data.js` で作る。
- ナビのリンクは `example.invalid` を指していて、押しても移動しない。各画面は個別の HTML を開く。

## ヘルプの画像を撮り直す（shoot.js）

画面を直したら、これを1回実行すればヘルプの画像がすべて新しくなる。

```
cd tools/help-shots && npm install    # 初回だけ（playwright-core。ブラウザは手元の Chrome を使う）
node tools/help-shots/shoot.js         # 書き出し → 19枚を撮影 → src/help-*.html に埋め込み
node tools/run-all.js                  # 画面が壊れていないか
```

1. `render.js` で画面を書き出す
2. 手元の Chrome で開いて操作し、**枠・矢印・番号を画面の上に描いてから**必要な範囲だけ撮る（`img/`・`.gitignore` 済み）
3. `src/help-*.html` の `data-shot="◯◯"` の場所に base64 で埋め込む（何度実行しても同じ結果）

最後に話題ごとの容量が出る。**1話題 200KB 程度まで**（押したときだけ読み込むが、スマホの回線で待たせないため）。

### 撮るものを足す・直す

`shoot.js` の `SHOTS` だけを触る。

| 項目 | 意味 |
|---|---|
| `page` | どの画面を開くか（`render.js` の `SHOTS` のキー） |
| `device` | `phone`（幅390）／`pc`（幅1280）。学生向けはスマホ、職員向けはPC |
| `steps` | 撮る前の操作（`click`） |
| `clip` | 写す範囲。並べた要素をすべて含む長方形を撮る |
| `marks` | 囲むもの。1つなら枠＋矢印、2つ以上なら枠＋番号（矢印は引かない・D46 と同じ） |

指定は座標ではなく**どのボタンか**（Playwright のセレクタ）なので、画面を直してもずれにくい。
新しい画像を足すときは、`src/help-*.html` に `<div class="help-img-todo" data-shot="◯◯" data-alt="説明">` を置いてから撮る。

### 撮るときの注意（実際にはまったこと）

- ナビは画面上部に張り付くので、撮影中は外している（外さないと写したい所がナビの下に隠れ、番号がナビに付いた）
- 「見えているもの」で絞ってから「何番目か」を選ぶ。PC 用の表とスマホ用の一覧が同じ HTML にあり、
  逆にすると隠れた方の要素を拾う
- 横いっぱいのボタンには矢印を引かない（左右に余白が無く、画面の外へはみ出した）
